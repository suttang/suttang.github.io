プライバシーポリシー

改定日: 2026-11-10

対象

personal-mail は、持ち主が自分の Gmail を自分の Mac の Claude Code / Codex から読み、新規メールや返信の下書きを作るための個人用コマンドラインツールです。扱うのは持ち主の Google アカウントのデータだけです。ほかの人は使えません。

使う許可とその用途

Google に求める許可は次の2つだけです。

  • https://www.googleapis.com/auth/gmail.readonly: メールの一覧・スレッド・本文を読むために使います。添付はファイル名・種類・大きさだけを確認し、中身は取得しません。
  • https://www.googleapis.com/auth/gmail.compose: 新規メールや返信の下書きを作る・直すために使います。この許可には Google の仕組みの上では送信も含まれますが、personal-mail に送信機能はありません。

送信（下書きの送信を含む）、削除（ゴミ箱・迷惑メールへの移動を含む）、ラベルの変更、既読・未読の変更、アーカイブ、下書きの削除はできません。送信は持ち主が Gmail の画面で行います。

保存するもの

  • OAuth の client ID、client secret、refresh token は、持ち主の Mac の Keychain に保存します。
  • access token は実行のたびに取り直し、メモリの中だけに保持します。保存しません。
  • ~/.config/personal-mail/config.json には、持ち主の Google アカウントのメールアドレスだけを保存します。
  • personal-mail 自身はメールの中身をファイルに保存せず、結果を画面（標準出力）に出すだけです。

メールの中身の扱い

持ち主の Mac で、持ち主の指示で動く AI アシスタント（Anthropic の Claude。Codex を使うときは OpenAI の Codex）が、要約・仕分け・返信の下書きのためにメールを読みます。

そのため、持ち主の指示で、メールの中身が Anthropic の API（Codex を使うときは OpenAI の API）に送られることがあります。送られたデータの扱いは、それぞれの提供元の規約に従います。AI アシスタントが読んだ内容は、そのアシスタントの会話の記録として持ち主の Mac に残ることがあります。

第三者への提供と利用の制限

Google API から得たデータを売ったり、広告に使ったりしません。上記の AI アシスタントの提供元（Anthropic、OpenAI）のほかの第三者に渡しません。汎用の AI モデルの学習に使いません。

Google API Services User Data Policy

personal-mail による Google API から受け取った情報の利用および転送は、Limited Use（利用制限）の要件を含む Google API Services User Data Policy に従います。

personal-mail's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

許可の取り消し

持ち主は、https://myaccount.google.com/permissionsから personal-mail の許可を外せます。持ち主が personal-mail auth logout を実行しても取り消せます。このコマンドは Google 側の token を取り消してから、Keychain の認証情報と設定を消します。

Privacy Policy

Last updated: 2026-11-10

Scope

personal-mail is a personal command-line tool for its owner to read their own Gmail and create new email and reply drafts through Claude Code / Codex on their own Mac. It handles only data from the owner's Google account. No one else can use it.

Permissions and their purposes

Only the following two Google permissions are requested.

  • https://www.googleapis.com/auth/gmail.readonly: Used to read message lists, threads, and message bodies. Only attachment names, types, and sizes are viewed; attachment contents are not retrieved.
  • https://www.googleapis.com/auth/gmail.compose: Used to create and update new email and reply drafts. Although this permission also allows sending under Google's permission system, personal-mail has no sending feature.

It cannot send mail (including drafts), delete mail (including moving it to Trash or Spam), change labels, mark mail as read or unread, archive mail, or delete drafts. The owner sends mail in the Gmail interface.

Stored information

  • The OAuth client ID, client secret, and refresh token are stored in the Keychain on the owner's Mac.
  • An access token is obtained for each execution and held only in memory. It is not persisted.
  • ~/.config/personal-mail/config.json stores only the email address of the owner's Google account.
  • personal-mail itself does not save email content to files. It only displays results on screen (standard output).

How email content is handled

An AI assistant running on the owner's Mac and acting on the owner's instructions (Anthropic's Claude, or OpenAI's Codex when using Codex) reads email to summarize it, organize it, and prepare reply drafts.

As a result, email content may be sent to Anthropic's API (or OpenAI's API when using Codex) at the owner's direction. The handling of data sent to these providers is governed by their respective terms. Content read by an AI assistant may remain on the owner's Mac as part of that assistant's conversation history.

Third-party sharing and use restrictions

Data obtained from Google APIs is not sold or used for advertising. It is not shared with third parties other than the AI assistant providers described above (Anthropic and OpenAI). It is not used to train general-purpose AI models.

Google API Services User Data Policy

personal-mail's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can remove personal-mail's access through https://myaccount.google.com/permissions. The owner can also revoke access by running personal-mail auth logout. This command revokes the token with Google before deleting the credentials from the Keychain and removing the configuration.
