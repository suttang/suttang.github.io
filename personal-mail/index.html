自分の Gmail を読み、下書きを作る個人用のツール

personal-mail は、持ち主が自分の Gmail を自分の Mac の Claude Code / Codex から読み、新規メールや返信の下書きを作るための個人用コマンドラインツールです。持ち主のほかには提供していません。

できること

  • メールの一覧・スレッド・本文を読む。
  • 添付ファイルの名前・種類・大きさを確認する。添付の中身は取得しません。
  • 新規メールや返信の下書きを作る・直す。

できないこと

送信（下書きの送信を含む）、削除（ゴミ箱・迷惑メールへの移動を含む）、ラベルの変更、既読・未読の変更、アーカイブ、下書きの削除はできません。送信は持ち主が Gmail の画面で行います。

メールの中身の扱い

持ち主の指示で動く AI アシスタントが、要約・仕分け・返信の下書きのためにメールを読みます。そのため、メールの中身が Anthropic の API（Codex を使うときは OpenAI の API）に送られることがあります。詳しくはプライバシーポリシーをご覧ください。

A personal tool to read Gmail and prepare drafts

personal-mail is a personal command-line tool for its owner to read their own Gmail and create new email and reply drafts through Claude Code / Codex on their own Mac. It is not offered to anyone other than its owner.

What it can do

  • Read message lists, threads, and message bodies.
  • View attachment names, types, and sizes. It does not retrieve attachment contents.
  • Create and update new email and reply drafts.

What it cannot do

It cannot send mail (including drafts), delete mail (including moving it to Trash or Spam), change labels, mark mail as read or unread, archive mail, or delete drafts. The owner sends mail in the Gmail interface.

How email content is handled

An AI assistant acting on the owner's instructions reads email to summarize it, organize it, and prepare reply drafts. As a result, email content may be sent to Anthropic's API (or OpenAI's API when using Codex). See the Privacy Policy for details.
